# Sunbeautyschool — сайт учебного центра

Статический сайт: чистый HTML + CSS + минимум JS, без сборщиков и фреймворков.
Хостится как набор файлов, поэтому весь контент отдаётся сервером сразу в HTML.

## Обязательные правила проекта

Перед любым изменением читать и выполнять:

- [docs/правила-проверки-изменений-на-сайте.md](docs/правила-проверки-изменений-на-сайте.md) — чек-лист, через который проходит каждое изменение перед публикацией.
- [docs/руководство-создание-сайтов-seo-geo.md](docs/руководство-создание-сайтов-seo-geo.md) — требования SEO, GEO и конверсии.

Ключевое из них, что действует постоянно:

1. **Контент — в HTML, а не в JS.** Тексты, цены, отзывы, новости, контакты пишутся прямо в разметке. JavaScript отвечает только за поведение (меню, кнопки оплаты, счётчики). Нейросети и часть поисковых роботов не выполняют JS.
2. **Ответ первым.** В первых 800–1000 символах страницы — прямой ответ с конкретикой: цена, срок, что получит человек. Никаких длинных подводок.
3. **Фактологическая плотность.** На странице минимум 2–3 числа: цены, сроки, количество выпускниц, часы.
4. **Schema.org обязательна.** `EducationalOrganization` на главной, `Course` + `Offer` на страницах курсов, `FAQPage` для блоков вопросов, `BreadcrumbList` для хлебных крошек. Проверять через Google Rich Results Test — 0 ошибок.
5. **Скорость.** Картинки в WebP с JPG-фолбэком, `loading="lazy"` для всего, что ниже первого экрана, у `<img>` всегда заданы `width` и `height`.
6. **Доступность и мобильные.** Контраст текста не ниже WCAG AA (4.5:1), кликабельные элементы не меньше 44×44 px.
7. **CTA видна без скролла** и на компьютере, и на телефоне. Текст кнопки — глагол пользы («Оплатить курс», «Стать моделью»), а не «Отправить».
8. **Служебные файлы обновляются вместе со страницами:** `sitemap.xml`, `robots.txt`, `llms.txt`. Новая страница — новая строка в sitemap и в llms.txt.
9. **robots.txt:** `OAI-SearchBot` и `PerplexityBot` разрешены, `GPTBot` запрещён.
10. **Уникальные `<title>`, `<h1>` и `meta description`** (150–160 символов) на каждой странице, canonical указывает на саму страницу.
11. **Внутренние ссылки:** минимум 2–3 релевантные ссылки с каждой страницы.
12. **Отзывы и соцдоказательства не удаляем** ради чистоты дизайна.

## Проверка перед публикацией

```
[ ] Текст виден в исходном коде страницы (Ctrl+U), а не появляется после JS
[ ] Консоль браузера чистая, нет 404 на картинки, CSS и JS
[ ] Мобильная версия не сломалась
[ ] Schema валидна
[ ] Ссылки внутри сайта ведут куда надо
[ ] sitemap.xml и llms.txt обновлены
```

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Главная: три двери, о школе, курсы, FAQ, отзывы, карта и контакты |
| `students.html` | Ученикам: список курсов с кнопками «Оплатить» |
| `course-depilation.html` | Курс депиляции: воск 8 500 ₽, сахар 8 500 ₽, полимер 10 000 ₽ |
| `course-cosmetology.html` | Курс косметолога-эстетиста: 20 000 ₽, 5 дней |

| `clients.html` | Прайс на процедуры |
| `models.html` | Требования к моделям, наборы, телеграм-группа |
| `assets/css/style.css` | Вся вёрстка и цвета |
| `assets/js/main.js` | Меню, кнопки оплаты. Вверху файла — `PAY_LINKS` |
| `assets/js/analytics.js` | Слоты для Яндекс.Метрики, GA4 и Clarity |
| `assets/img/` | Логотип и фотографии, в JPG и WebP |
| `mockups.html` | Черновые варианты дизайна, на боевой сайт не выкладывается |

## Дизайн

Вариант «три тона»: один цвет тиффани в трёх насыщенностях плюс золото.

| Роль | Значение |
|---|---|
| Светлый тиффани | `#DFF2F0`, фон страниц `#EFF8F7` |
| Основной тиффани | `#7FD3CE` |
| Глубокий тиффани | `#26706D` — кнопки и цены |
| Золото декоративное | `#C9A227` — линии и рамки |
| Золото для текста | `#8A6A12` — контраст на белом |
| Тёмный | `#123634` — текст и подвал |

Шрифты: Cormorant Garamond для заголовков, Manrope для текста.
Логотип: `assets/img/logo-mark.png` — вырезан из исходной картинки, фон прозрачный.

## Что ещё не заполнено

- Телефон, адрес салона, ссылки на мессенджеры и соцсети — сейчас стоит «уточняется».
- Карта: вставить iframe Яндекс.Карт в `index.html`, блок «Как нас найти».
- Прайс в `clients.html` — везде «уточняется».
- Программа и стоимость курса педикюра.
- Отзывы — блок на главной пока пустой, шаблон карточки лежит в комментарии рядом.
- `PAY_LINKS` в `assets/js/main.js` — ссылки на оплату.
- Счётчики в `assets/js/analytics.js`.
- Домен: во всех страницах указан `https://sunbeautyschool.ru`. Если домен другой — заменить в `canonical`, `og:url`, `sitemap.xml`, `robots.txt`, `llms.txt`.

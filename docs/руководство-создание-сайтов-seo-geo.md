# Руководство для веб-разработчика: SEO + GEO + CRO

Практическая выжимка из исследования — что применять при создании сайтов, чтобы они попадали в топ Яндекса, цитировались нейросетями и конвертировали посетителей в лиды.

---

## 1. ПРАВИЛА СОЗДАНИЯ САЙТА

### Технический фундамент (обязательно на каждом проекте)

**Рендеринг**
- Использовать SSR (server-side rendering) или гибридную модель. Чистый SPA на JS — плохо: многие LLM не выполняют JavaScript и не увидят контент.
- Критически важный контент должен быть в HTML-ответе сервера, а не подгружаться скриптами.

**Скорость и стабильность**
- Время до первого контента < 3 секунд.
- PageSpeed Score > 90.
- Время ответа сервера < 200 мс.
- Полная мобильная адаптация (не масштабирование, а полноценная mobile-версия).

**Структурированная разметка Schema.org — обязательный минимум:**
- `Organization` — данные компании
- `Person` — авторы статей
- `Article` — все статьи блога
- `FAQPage` — блоки вопрос-ответ
- `Product` — карточки товаров/услуг
- `BreadcrumbList` — хлебные крошки

Наличие структурированных данных даёт +21.6% к вероятности цитирования в ИИ. Полное покрытие всех типов контента может дать +30-40% видимости в ответах ИИ.

**Файлы для роботов**
- `robots.txt`: разрешить `OAI-SearchBot` (OpenAI) и `PerplexityBot`, заблокировать `GPTBot` (обучающий бот — забирает контент без пользы).
- `llms.txt` в корне сайта — описание сайта и ключевые URL для ИИ-агентов. Прямого доказанного эффекта нет, но вреда тоже — стоит внедрять.
- `sitemap.xml` — обязательно, актуальный.

### Структура и UX

- Чёткая иерархия главной страницы с логичными категориями (это может снизить показатель отказов с 60% до 30% и увеличить время на сайте с 40 секунд до 2-3 минут).
- Простая навигация — минимум когнитивной нагрузки.
- Читаемая типографика, контрастные CTA.
- Видео на странице увеличивает конверсию до 86%.

### Контент под ИИ (GEO — Generative Engine Optimization)

Правила написания текстов для страниц:
1. **Принцип «ответ первым»**: прямой краткий ответ на вопрос пользователя в первых 800-1000 символах. Дальше — детали.
2. **Фактологическая плотность**: конкретные числа, даты, имена, сравнения. Добавление статистики → +40% к видимости в ИИ.
3. **Структура**: таблицы, списки, FAQ-блоки с разметкой Schema.
4. **Прозрачное авторство**: имя, фото, регалии, ссылки на соцпрофили автора.
5. **Глубина**: длинные экспертные материалы (>1500 слов) для Gemini; свежий контент для ChatGPT.

### Аналитика — ставится сразу при запуске

- Яндекс.Метрика (обязательно для РФ)
- Google Analytics 4
- Hotjar или Microsoft Clarity (тепловые карты, записи сессий)
- Google Search Console + Yandex.Webmaster
- UptimeRobot или Pingdom (мониторинг доступности)
- Инструмент A/B-тестирования (VWO, AB Tasty, Convertize, Statsig)

## 2. КОНКРЕТНЫЕ РЕКОМЕНДАЦИИ

### По архитектуре

- Next.js / Nuxt / Astro с SSR или SSG — предпочтительнее чем чистый CRA/Vue SPA.
- WordPress остаётся валидным вариантом (он и так серверный).
- Если клиент настаивает на SPA — сделать pre-rendering ключевых страниц через Prerender.io или аналог.

### По контенту (что советовать клиентам)

- Публиковать 1-2 экспертные статьи в неделю.
- Каждая статья — с разметкой Article + FAQ.
- Обязательно указывать автора со всеми регалиями.
- Регулярно обновлять старые статьи (ChatGPT предпочитает контент на 393-458 дней свежее, чем Google).

### По внешним сигналам (это влияет на цитируемость в ИИ сильнее, чем ссылки)

Брендовые упоминания дают гораздо больший эффект, чем обратные ссылки:
- Упоминания на YouTube — корреляция 0.737 с AI-видимостью
- Упоминания в вебе — 0.664
- Классические backlinks — всего 0.218

Куда размещаться в РФ:
- **Habr** — IT/технологическая экспертиза
- **VC.ru** — бизнес-контекст
- **Otzovik, Irecommend** — потребительские отзывы
- **Yandex Zen / Дзен** — охват через контентную экосистему

### По конверсии (проверенные приёмы с цифрами)

- Сокращение полей формы: +15-120% конверсии.
- Упрощение регистрации (много страниц → одна): до +500% лидов.
- Изменение текста CTA (напр., «Отправить» → «Получить предложение»): +25% кликов.
- Добавление отзывов, логотипов клиентов, соцдоказательств — стандартный рост доверия.
- Видео на лендинге: до +86% конверсии.

### По ИИ-оптимизации (специфика по платформам)

| Платформа | Что любит |
|-----------|-----------|
| ChatGPT | Свежий контент, источники из Bing |
| Perplexity | Упоминания в рейтингах, авторитетные источники со ссылками |
| Gemini | Длинные (>1500 слов) экспертные статьи на собственном домене |
| Яндекс Neuro | Топ-5 обычной выдачи Яндекса — то есть классическое SEO |
| YandexGPT | Качественный русскоязычный контент |
| GigaChat | Русскоязычный практический контент |

Ключевой инсайт для РФ: **лучший способ попасть в Яндекс Neuro — быть в топ-5 обычного Яндекса.** Отдельная оптимизация под Neuro не нужна.

### По A/B-тестированию

- Минимум **10 000 посетителей на вариацию** для надёжного результата.
- Минимум **300-500 конверсий на каждую версию**.
- Уровень значимости — 95% (p-value < 0.05), мощность — 80%.
- Если трафика < 10 000 уникальных/месяц — A/B-тесты почти бесполезны, использовать качественный анализ (heatmaps, интервью).
- Bayesian-подход достигает значимости на ~30% быстрее frequentist.
- Обязательно рассчитывать размер выборки ДО запуска теста через калькулятор.

## 3. ЧТО ОТСЛЕЖИВАТЬ И КОГДА

### Ежедневно

| Задача | Инструмент | Критерий |
|--------|-----------|----------|
| Доступность сайта (uptime) | UptimeRobot, Pingdom | Без простоев, ответ сервера < 200 мс |
| Скорость ключевых страниц | Автоматизированный мониторинг | < 3 сек до контента |
| Ошибки индексации | Google Search Console, Yandex.Webmaster | Нет новых 4xx / 5xx |

### Еженедельно

| Задача | Инструмент | Критерий |
|--------|-----------|----------|
| Публикация 1-2 GEO-статей | CMS | Свежий контент выходит |
| Небольшой A/B-тест (CTA, поле формы) | VWO / AB Tasty / Convertize | Гипотеза сформулирована, тест запущен |
| Анализ поведенческих метрик | Яндекс.Метрика, GA4 | Отслеживать тренд отказов, времени на сайте |
| Анализ heatmaps и записей сессий | Hotjar, Microsoft Clarity | Найти 1-2 узких места на страницу |

### Ежемесячно

| Задача | Инструмент | Критерий |
|--------|-----------|----------|
| Полный технический аудит | Screaming Frog, Sitebulb, GTmetrix | Исправление всех критических ошибок |
| Валидация Schema | Google Rich Results Test, Schema Validator | 0 ошибок разметки |
| Проверка robots.txt и llms.txt | Ручная + валидаторы | Правильные разрешения для ИИ-ботов |
| Мобильная адаптация | Google Mobile-Friendly Test | Всё OK |
| AI-аудит: цитируется ли сайт | ChatGPT, Perplexity, Gemini, Яндекс Neuro (ручная проверка 3-5 ключевых запросов) | Упоминания сайта, точность инфо |
| Комплексный A/B-тест ключевой страницы | VWO / Statsig | Статистически значимый результат |
| Анализ путей пользователя, воронки | Яндекс.Метрика, Hotjar | Устранение отвалов в воронке |
| Внешние упоминания (PR, публикации) | Ручная работа + PR-сервисы | Рост упоминаний на Habr, VC.ru, Otzovik |
| Анализ бэклинков | Ahrefs, Semrush | Рост качественных ссылок |
| Проверка результатов ежемесячных тестов на достоверность | Калькулятор размера выборки | Убедиться, что p-value < 0.05 и выборка достаточна |

### Процедура перепроверки результатов (обязательно перед внедрением)

1. **Сбор данных** — по мероприятию.
2. **Количественная проверка** — для A/B: пересчитать размер выборки. Для GEO: сверить, что ИИ процитировал ТОЧНУЮ информацию (нейросети галлюцинируют).
3. **Качественный анализ** — не было ли параллельных изменений, сезонности, всплеска трафика из нового канала.
4. **Оценка бизнес-влияния** — +5% конверсии при 2% базе и 10 000 посетителей = 50 лидов/мес. Стоит ли внедрять?
5. **Решение** — внедрить / отклонить / углубить тест.

## 4. ЧТО ЕЩЁ ВАЖНОГО ЕСТЬ В ФАЙЛЕ

Осталось несколько идей, не вошедших в основные блоки, но полезных для понимания контекста:

### Специфика российского рынка

- **Двойная экосистема**: локальный Яндекс + западные ИИ через VPN (ChatGPT, Gemini, Perplexity). Пользователи с VPN сталкиваются с медленными соединениями — быстрый сайт даёт им ощутимое преимущество в удержании.
- **YandexGPT** глубоко интегрирован с Алисой, Яндекс.Браузером и другими продуктами экосистемы — попадание туда даёт большой охват в РФ.
- **GigaChat** интегрирован в Sber.Salut (голосовые помощники, смарт-устройства).
- ChatGPT в русскоязычных задачах иногда уступает YandexGPT и GigaChat — но в сложной логике всё ещё лидирует. Контент нужно оптимизировать и под глобальные, и под локальные модели.

### Как алгоритмы Яндекса отличаются от Google

- Яндекс придаёт **сильно больший вес поведенческим факторам**, чем Google. Показатель отказов, время на сайте, глубина просмотра, возвраты к поиску — для Яндекса это критично.
- Актуальные алгоритмы Яндекса: **«Вега», «Оригами», «Тайфун»** — все активно используют поведенческие метрики.
- **Возврат к поиску** — самый мощный негативный сигнал: пользователь не получил ответ и пошёл искать дальше.

### Про «накрутку» поведенческих факторов

- Не работает. Приводит к штрафам. Единственный путь — качественный контент и UX.

### Ключевая мысль про GEO vs SEO

- SEO — попасть в топ ссылок.
- GEO — стать источником, из которого ИИ **синтезирует свой ответ**.
- Это разные задачи, требующие разного подхода к контенту. В эпоху «zero-click» упоминание бренда в ответе ИИ (даже без клика на сайт) — уже успех: формирует узнаваемость и доверие.

### Про метрику Share of Voice / Citation Rate

- Новая метрика для эпохи ИИ-поиска: доля цитирований бренда в ответах ИИ.
- Постепенно вытесняет по важности классические «позиции в выдаче» и «органический трафик».

### Про галлюцинации ИИ

- ИИ уверенно выдаёт неверную информацию. Каждое цитирование сайта в ответе ИИ нужно сверять с оригиналом.
- Если ИИ переврал факты — репутационный риск, плюс алгоритм может пометить сайт как «ненадёжный».

### Про инструмент для сравнения ИИ-ответов

- Сервис **Talkory** — позволяет сравнивать ответы разных ИИ на один и тот же запрос. Полезно для GEO-аудитов.

### Синергия направлений

- Все четыре блока (техника, GEO-контент, поведенческие, CRO) взаимосвязаны:
  - Хорошая техника → лучше поведенческие сигналы → выше в Яндексе.
  - Хороший контент → лучше поведенческие → выше конверсия.
  - Правильная Schema → цитируется ИИ → приходит новый трафик.
- Работа в одном направлении усиливает результаты в других — это не отдельные задачи, а единая философия.

### Экономический порог для A/B-тестирования

Явно проговорено в исследовании: сайтам с трафиком **менее 10 000 уникальных/мес** классические A/B-тесты малополезны. Для таких проектов ставка — на качественную аналитику (тепловые карты, записи сессий, интервью) и на очевидные улучшения по best practices, а не на статистические эксперименты.

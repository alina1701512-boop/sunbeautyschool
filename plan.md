## 3. Домен ⚠️

**Сейчас во всех файлах прописан временный домен `https://sunbeautyschool.ru`.**
Когда домен будет куплен и окажется другим, заменить его в четырёх местах:

- [ ] `<link rel="canonical">` и `<meta property="og:url">` — во всех семи HTML-страницах
- [ ] `sitemap.xml` — все семь адресов
- [ ] `robots.txt` — строка `Sitemap:`
- [ ] `llms.txt` — все ссылки

Быстрая замена одной командой из папки сайта:

```bash
grep -rl "sunbeautyschool.ru" --include="*.html" --include="*.xml" --include="*.txt" . | xargs sed -i "s|https://sunbeautyschool.ru|https://НОВЫЙ-ДОМЕН|g"
```

После замены проверить: `grep -r "sunbeautyschool.ru" .` — не должно остаться ничего, кроме этого файла.

## 4. Хостинг и публикация

- [x] GitHub Pages включён — сайт открывается по адресу https://alina1701512-boop.github.io/sunbeautyschool/
      Это временное превью, чтобы показывать работу Регине. Обновляется само при каждом `git push`.
- [ ] Привязать купленный домен: в настройках репозитория Settings → Pages → Custom domain,
      либо перенести файлы на обычный хостинг
- [ ] Включить HTTPS
- [ ] Проверить, что сайт открывается и по `www`, и без него, с редиректом 301 на основной вариант

Пока домена нет, `canonical` на всех страницах указывает на будущий адрес `sunbeautyschool.ru`.
Это сделано намеренно: превью на GitHub Pages не попадёт в поиск и не будет потом
конкурировать с настоящим сайтом. После покупки домена выполнить пункт 3.

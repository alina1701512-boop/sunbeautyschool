# Sunbeautyschool

Сайт учебного центра эстетической косметологии: курсы депиляции, педикюра и косметолога-эстетиста.

Статический сайт — чистый HTML, CSS и немного JavaScript. Без сборщиков, фреймворков и базы данных: файлы кладутся на любой хостинг и работают.

## Страницы

| Адрес | Что там |
|---|---|
| `index.html` | Главная: три раздела, о школе, курсы, вопросы, отзывы, карта и контакты |
| `students.html` | Ученикам — список курсов с кнопками оплаты |
| `course-depilation.html` | Курс депиляции: воск 8 500 ₽, сахар 8 500 ₽, полимер 10 000 ₽ |
| `course-cosmetology.html` | Курс косметолога-эстетиста: 20 000 ₽, 5 дней |
| `course-pedicure.html` | Курс педикюра: программа и цена по запросу |
| `clients.html` | Прайс на процедуры |
| `models.html` | Требования к моделям, наборы, телеграм-группа |

## Где открыть

## Как посмотреть локально

```bash
python -m http.server 5173
```

Затем открыть http://localhost:5173

## Что и где менять

| Что нужно поменять | Где |
|---|---|
| Телефон, адрес, режим работы | `index.html`, блок «Как нас найти», и подвал каждой страницы |
| Карта | `index.html`, блок «Как нас найти» — вставить iframe Яндекс.Карт |
| Цены в прайсе | `clients.html` |
| Отзывы | `index.html`, блок «Отзывы» — шаблон карточки лежит в комментарии рядом |
| Ссылки на оплату | `assets/js/main.js`, переменная `PAY_LINKS` |
| Счётчики аналитики | `assets/js/analytics.js` |
| Цвета и вёрстка | `assets/css/style.css` |
